# V1 真实环境验收交接

本地验收场景为非机动车违停。真实环境批次按用户“继续本地开发，真实环境授权后补”的决定单列。开发包、模型质量、目标机容量和生产上线分别留证。当前场景配置用 all_declared 选题、模型定位和显式绑定的合成 CPU 像素工具；真实图像需要具有相应能力和独立评测依据的部署及工具绑定。

| 待验证项 | 启动所需的实际输入 | 应留存的验收证据 |
|---|---|---|
| 设备与数据 | 获准的数据集版本、样本使用范围、设备/相机身份及真实 Region 的几何资源、原图摘要。数据保存在获准环境。 | 使用受信宿主登记原图，逐项核验媒体哈希、范围、坐标变换和 N01 Context。留出集按数据来源去重，真值与模型预测分别固定。 |
| 真实能力联调 | 目标 RTX 4090 主机标识、驱动/容器版本、经授权的远程 Provider、本地能力版本、允许调用次数/费用及停止条件。凭证由宿主保管。 | 从正式受理入口运行已签 Bundle，逐节点核对 configured/actual provider、派发回执、图片与 Object 输入、联合请求数、事实选择、具名工具结果及最终 Decision。记录峰值显存、并发、延迟和恢复。 |
| 业务质量 | 业务方批准的违停口径和阈值、遮挡与边界争议的独立复核人、明确的测试集及评分协议。实际放行行为从业务处置记录取得。 | 分别报告主体发现、定位、Fact、几何、规则和任务层结果；保留未标注、部分覆盖、弃判、无观测放行及各自分母。保存可重算输入、争议裁决和归因。 |
| 部署与保管 | 正式身份提供者、签名信任根、激活与证据权限、密钥恢复位置、运维维护窗口和发布授权。 | 在受权环境完成签名准入、只读证据查询、观测和独立恢复验证。宿主保管的正式人审、标签及信任配置需纳入宿主备份；Runtime 包保存其身份与摘要。 |

可复用接口、合成运行证据及当前技术边界见 [WP-05 运行验收](../WP-05/FINAL_ACCEPTANCE_REPORT.md)、[WP-06 回放与评测验收](../WP-06/FINAL_ACCEPTANCE_REPORT.md)、[WP-07 API 合同](API_CONTRACT.md)。待验证项统一记录于此，获取资源时沿原包追加真实证据。
