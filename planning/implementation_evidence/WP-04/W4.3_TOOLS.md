## 变更与决策

- `src/jimu_runtime/tools/registry.py` 按 capability、contract、implementation、IO Schema 和资源类型核对工具登记。CPU 工作者校验宿主登记的命令制品摘要，经资源账本与派发闸门后由隔离监督器运行。有界远端传输由宿主注册，供应方在途额度通过可信终态证明结算。
- `src/jimu_runtime/tools/executor.py` 核对 Release、Execution、处于运行中的 NodeRun/Attempt、N03 的 Profile grounding binding 或 N05 的 Object/Plan/step 和 Producer 声明。接口验证原图坐标与证据作用域，按真实请求字节执行 IO 限制，并从单个可信 ToolResult 分别构造各命名输出的 Fact 候选。错误和无派发记录使用现有 ToolExecution 形态。证据策略允许时，宿主存储回调可以保存完整原始回包。摘要从收到的完整字节计算。
- `src/jimu_runtime/domain/validation/invocations.py` 允许同一 Attempt 的不同合法工作单元。N03 按 Profile 区分，N05 按同一 Object、Profile 和 Plan 下的 step 区分。跨来源、跨属主、重复执行 ID 或重复工作单元继续被拒绝。后续同文件的 Model Gateway 区段由 W4.1 负责人维护。
- `src/jimu_runtime/tools/__init__.py` 提供工具入口，`tests/contract/test_wp04_tool_executor.py` 复用实际 Bundle 编译、签名与准入设施。隔离合成 Tool 可同时用于 N03 和 N05。
- 跨轮步骤身份由 `StepAttemptStore` 与 W4.5 接线保存。工具执行器输出不可变记录和候选 Fact。权威资格依赖调用者的持久 fence 与状态核验。现有 ToolExecution、Fact 和 Selection wire 继续使用 1.0.0。

## 嵌套模型调用补充

经主控放行，模型支持的 Tool 可在获得实际派发许可后，通过同一受信 Gateway 回调提交一次辅助模型请求。ToolDefinition 固定 ModelBinding，Gateway 固定模型用途和子 Attempt 归属，并从持久调用记录核验。工具运行时核对模型回执的 Execution、NodeRun、Attempt、Profile、Object、trace、模型绑定、顺序及回包引用摘要。可用的工具结果要求实际成功回执与工具引用完全一致。工具自行提交的调用记录、没有实际回执的成功主张及同 ID 内容替换均无法生成候选 Fact。失败分支可保留实际核验过的嵌套调用。有效原始图像仍须匹配固定素材摘要。非模型 Tool 的既有单步入口保持兼容。

## 原生代码审查整改

原生审查以主控限定 diff 为基线，记录了 4 项 P1 和 6 项 P2。下列回归使用合成 Tool、隔离 Linux CPU worker、宿主资源账本及临时签名 Bundle。

| 级别与发现 | 处置与回归 |
|---|---|
| P1 执行文件身份 | SHA-256 计算覆盖实际交给监督器的 sealed memfd 字节。监督器仅转交已封存且与 argv 精确匹配的文件描述符。回归在已完成校验且等待派发时原子替换原路径，隔离进程仍执行原脚本。 |
| P1 失败回包终态凭据 | 正常回包和已派发异常的完整回包走同一终态核验路径。可信失败终态回执释放单槽后，下一个远端 Tool 可运行，无证据或错误凭据继续保持占用。 |
| P1 存证等待 | 存证使用 Tool 截止时间的剩余预算。存证任务延迟响应取消时，执行入口仍在预算到期返回失败审计。已收到的完整回包摘要、字节数和实际版本保留，晚到资产不进入本条记录。 |
| P1 存证 I/O 失败 | 存储异常产生固定审计诊断，保留已派发事实和完整回包摘要，记录中仅含已验证保存的 Evidence。存证故障不触发 Tool 物理重试。 |
| P2 远端激活与截止 | 宿主账本的资源预留、ARMED 和激活在工作线程中处理。最终 SQLite 写锁内检查单调时钟 deadline，发送前复核。取消或到期可补偿尚无发送权的 ARMED。已记录发送授权后的不确定状态维持普通远端结算规则。 |
| P2 取消期间的预留 | Tool 与 Gateway 共用 `acquire_with_compensation`。阻塞预留晚完成时，由拥有资源的工作线程补偿。回归关闭短生命周期事件循环后重新预留，确认槽位可用。 |
| P2 部分输出与兄弟 Fact | 工具字段约束和 FactSchema 逐项同时校验。可分离的可选祖先移除后，合法兄弟继续保留。显式 UNKNOWN 的祖先为空时可裁剪，已完全省略时保持原结果。新编译和准入拒绝无法独立省略的多个必填叶。 |
| P2 已核实的实现版本 | 失败回包版本和独立观察合并。回包未报版本时可沿用精确核验观察，冲突时记 `unavailable`。 |
| P2 失败诊断关联 | 失败结果仅引用已通过 Evidence 作用域和保存状态检查的证据。回归验证未知证据 ID 被过滤，实际诊断证据继续可追溯。 |
| P2 重复响应资产 | Worker 与存证通道报告相同不可变 EvidenceAsset 时按 ID 合并一次，内容或作用域冲突仍拒绝。回归验证相同资产的正常和失败回包。 |
