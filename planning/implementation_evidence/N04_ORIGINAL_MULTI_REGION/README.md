# N04 原图多区域单请求实测

使用此前三张 1536 × 1024 合成图、历史 N03 原图坐标和正式签名 Bundle 的问题与答案枚举。每张原始 PNG 只发一次，使用短 ID 标识对象，停车保留两个成员坐标，人行道区与对象框都换为同一个 0–999 千分坐标系。红框/像素区域措辞适配为坐标指向。服务为同一内网 Qwen3_5-9B 端点，串行请求，使用结构化 JSON 输出与服务默认采样和思考配置。读取三个真实 HTTP 200 / stop 响应，无重试。原始 Task、N05 和 N06 没有重跑。

| 场景 | 历史调用 / 新调用 | 历史 HTTP 往返累计 / 本次秒数 | 与独立图像参考相符 | 与历史答案一致 |
|---|---|---|---|---|
| 两辆车一个停车组 | 1 / 1 | 6.129 / 3.491 | 4/4 | 4/4 |
| 口罩 | 1 / 1 | 1.488 / 0.853 | 2/2 | 2/2 |
| 纸箱 | 9 / 1 | 153.045 / 29.021 | 4/9 | 4/8，历史有一个框未返回 Fact |

停车评分为车型、组停车位置及两辆车各自的停放状态。口罩评分为脸部可判断与佩戴状态。每个纸箱各有一个问题。成功返回全部 15 个分类项。自由文本证据不作精确匹配。历史计时取正式正例的 N04 上游 HTTP round_trip_s，本次为从发起 HTTP 请求到收到完整响应的数据；都不含本地编译提示和序列化的准备时间。三图历史累计 160.662 秒，本次累计 33.365 秒。非同时对照、每图单次，未控制模型排队、缓存或采样差异。历史货物有一轮不完整回复耗费 73.617 秒。

盲评由独立 AI 仅查看相同原图、N03 框和业务区域进行。停车与口罩所有类别可见。货物 r1、r3 的落地可见，r2、r4 的支撑可追至前两者，其余五个均缺可确认的落地或支撑证据。本次九个回答都是占道。四个可证实的占道均命中，五个不可辨均被确定回答。对同样八个历史有答案的货物框，历史和盲评相符 5/8，新模式相符 4/8。没有明确不占道的盲评货物框。这批图片未单独测得真阴性识别率、跨框定位正确率或生产准确率。
